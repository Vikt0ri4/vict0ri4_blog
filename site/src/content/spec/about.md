# 关于 vict0ri4

vict0ri4 是我的个人自留地——更准确地说，是我练习 Linux 与自托管运维的地方。写博客是个借口，真正想弄明白的是它底下的服务器、网络与容器：从内核参数到反向代理，从构建流水线到端口与权限的边界，能亲手跑通一遍的，我都想亲手跑通。

## ✦ 为什么会有这个站

- 起点是练习。我想让一个东西完整地从内核、网络、反向代理一路走到部署，而不是只停留在"读过文档"的阶段。
- 这里的大部分文章都写于这个过程之中：装 Gentoo、写 nftables 规则、折腾 2.4GHz 热点与虚拟化网络，以及那些踩过之后值得记下来的小失败。
- 我希望它是一份长期可读的笔记，而不是一堆过期的操作记录——所以每篇文章尽量写清背景、取舍与结果。
- 长期目标很简单：让这个角落一直在线、始终属于自己，几年之后自己回来读还能看懂。

## ✦ 我们做了什么

前端主题来自开源项目（基于 Astro 的 Shirone），视觉设计并非出自我们；我们做的是部署与工程这一侧——架构设计、容器化、构建可复现，以及让站点按我们想要的方式运转的个性化改造。我们是一个三人小组：作为组长，我负责架构设计、技术方向与验收；前端搭建、排版与文档由一位队友负责；构建、测试与功能完整性验证由另一位负责。

站点目前包含文章、说说、相册、项目、技能、时间线与友链等页面；搜索索引、图片缩略图与字体子集都在构建期自动生成，部署侧还配有一键构建与启动脚本、静态资源缓存与压缩策略，以及与官方搭建文档逐条对照的自查清单。

## ✦ 技术栈

- **框架**：Astro 7 与 Svelte 群岛组件，基于开源主题
- **内容**：Markdown / MDX 文章与说说，构建期生成离线索引与缩略图
- **运行与部署**：Docker 与 Podman 双运行时——一套代码、两种环境行为一致，采用多阶段构建
- **对外服务**：Nginx——静态源站，外加作为唯一对外入口的反向代理
- **工具链**：Node.js ≥ 22.12 与 pnpm 9.14.4，由 corepack 锁定版本
- **搜索**：Pagefind 离线全文索引，在部署时生成
